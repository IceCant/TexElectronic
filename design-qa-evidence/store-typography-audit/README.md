# Storefront typography audit

Scope: public storefront typography in the shared Style 1/2/3 system, reviewed on desktop and at a 390 × 844 mobile viewport.

## Flow

1. **Desktop storefront before — needs improvement.** Supporting copy in the trust strip, category chips, product metadata, and secondary actions used an 8–10px scale that was difficult to scan.
2. **Desktop storefront after — healthy.** Navigation, support copy, calls to action, trust details, chips, and catalogue controls now use a clearer hierarchy with an 11–12px supporting-text floor.
3. **Product cards after — healthy.** Product names use 17px type, SKU/brand metadata uses 11px, descriptions use 12px, and price labels and actions remain visually distinct.
4. **Mobile storefront after — healthy.** The larger scale reflows cleanly at 390px; primary copy remains prominent while trust details, chips, and product information stay readable without horizontal page overflow.

## Evidence limits

Screenshots support visible hierarchy, reflow, and likely legibility findings. This does not replace device testing at the user's preferred OS text scaling or a complete WCAG conformance audit.
